Firebase Cloud Sync

Connect to Firestore for real-time sync across devices. All players see live updates.

How to Setup Firestore

  1. Go to Firebase Console
  2. Create a new project (or use existing)
  3. Enable Firestore Database (Start in test mode)
  4. Go to Project Settings > General > Your apps > Web
  5. Copy the firebaseConfig object values into the fields above
  6. Click Connect & Sync

Security: For production, set Firestore rules to allow read/write only to authenticated users.
